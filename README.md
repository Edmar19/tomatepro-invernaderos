# tomatepro-invernaderos
TomatePro Invernaderos es una herramienta digital de gestión agronómica y financiera diseñada para productores de jitomate. Permite calcular el punto de equilibrio por cosecha, monitorear el Déficit de Presión de Vapor (DPV), registrar mermas traducidas a pérdidas en $ MXN y gestionar periodos de carencia fitosanitaria (PHI).
